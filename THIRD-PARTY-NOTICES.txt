    HOW THESE WERE DETERMINED - stated plainly, because it bounds how much the
    table above can be relied on. The shipped plugin binaries do NOT embed their
    upstream library's license. The only license string inside them is VLC's own
    module-wrapper header ("Copyright (C) the VideoLAN VLC media player
    developers / Licensed under the terms of the GNU Lesser General Public
    License, version 2.1 or later"), which describes the VLC glue code, not the
    statically-linked codec. Every row above therefore comes from the upstream
    project's own published licensing, EXCEPT libfaad/FAAD2, which was verified
    directly against upstream's COPYING and README (see the note below).

    NO GPL-2.0-ONLY COMPONENT IS PRESENT. Every GPL plugin listed is
    "or-later", which upgrades to GPL-3 and is therefore conveyed cleanly under
    TelegArm's own GPL-3.0-only license and the shipped LICENSE.txt. The GPL-2.0
    text is reproduced in full below for the avoidance of doubt.

    CORRECTION ON libfaad. An earlier internal audit recorded FAAD2 as
    "GPL-2.0-only + addendum", which would have been a genuine license CONFLICT
    with a GPL-3.0-only application. That is REFUTED. FAAD2's upstream README
    and COPYING state: "you can redistribute it and/or modify it under the terms
    of the GNU General Public License as published by the Free Software
    Foundation; either version 2 of the License, or (at your option) any later
    version." The Nero addendum forbids NON-GPL use and adds an attribution
    requirement; it does not remove the "or later" option. There is no conflict
    and no need to drop the plugin on license grounds.

    FAAD2 REQUIRED ATTRIBUTION. The addendum specifies that the "appropriate
    copyright message" mentioned in GPLv2 section 2c must read:

        Code from FAAD2 is copyright (c) Nero AG, www.nero.com

    That statement is reproduced here to satisfy the requirement.
    FAAD2 is Copyright (C) 2003-2005 M. Bakker, Nero AG, http://www.nero.com.
    Upstream additionally warns that use of FAAD2 may require the payment of
    patent royalties, and disclaims any warranty or indemnity on that point.

    LGPL "replaceable library" compliance: libVLC ships as separate,
